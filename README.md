# WebGL 3D Viewer

Просмотр 3D-моделей в браузере. Без установки, без плагинов — загрузи файл и вращай.

## Возможности

- Загрузка моделей: `.glb`, `.gltf`, `.obj`, `.fbx`, `.stl`
- Управление камерой: вращение, зум, панорамирование
- Drag & drop файла прямо в окно
- Автомасштаб — модель вписывается в кадр
- Поддержка материалов и текстур (PBR)
- Адаптив под десктоп и мобильные
- Полностью в браузере — файлы не отправляются на сервер

## Запуск

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite (обычно http://localhost:5173).

### Сборка

```bash
npm run build
```

Готовые файлы в папке `dist/`.

## Управление

- Левая кнопка мыши — вращение
- Колесо — зум
- Правая кнопка или Shift + мышь — панорамирование
- Двойной клик — сброс камеры

## Поддерживаемые форматы

| Формат | Расширения | Особенности |
|--------|-----------|-------------|
| glTF | `.glb`, `.gltf` | Рекомендуемый, PBR, анимации |
| OBJ | `.obj`, `.mtl` | Универсальный |
| FBX | `.fbx` | Игровая индустрия |
| STL | `.stl` | 3D-печать, без текстур |
